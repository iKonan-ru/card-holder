# Security Policy

## Безопасность данных

### Локальное хранение

Card Holder хранит все данные **исключительно локально** в IndexedDB вашего браузера:

- Данные **НЕ** отправляются на сервер
- Данные **НЕ** синхронизируются между устройствами
- Данные **НЕ** передаются третьим лицам
- Приложение работает полностью offline

## Шифрование данных

### Мастер-пароль

При первом запуске приложение предлагает создать мастер-пароль. Без него доступ к данным невозможен.

- Мастер-пароль **нигде не хранится** - ни в зашифрованном, ни в открытом виде
- Ключ шифрования существует **только в памяти** текущей сессии; при блокировке или закрытии вкладки удаляется
- В `localStorage` хранится только соль (случайные байты) и верификационный токен (зашифрованная строка для проверки правильности пароля)
- **Восстановление невозможно**: если пароль утерян - данные недоступны

### Алгоритм шифрования

Чувствительные поля карт (CVV, срок действия, имя, PIN и другие) шифруются алгоритмом **AES-GCM 256-бит** с уникальным IV для каждой записи.

В IndexedDB в открытом виде хранится только:

- `pan` - номер карты (используется как ключ индекса)
- `order` - порядок отображения

Все остальные поля упакованы в зашифрованный `encryptedPayload`.

### Производная ключа (PBKDF2)

Ключ шифрования выводится из мастер-пароля с помощью **PBKDF2**:

| Параметр      | Значение            |
| ------------- | ------------------- |
| Алгоритм хэша | SHA-256             |
| Итерации      | 600 000             |
| Длина ключа   | 256 бит             |
| Длина соли    | 16 байт (случайная) |

### Защита от перебора паролей

Ввод пароля защищён rate limiting:

| Событие              | Поведение                                        |
| -------------------- | ------------------------------------------------ |
| 1–3 неверные попытки | Немедленный ответ (без задержки)                 |
| 4+ неверные попытки  | Экспоненциальная задержка (×2 с каждой попыткой) |
| 10+ неверных попыток | Блокировка на **15 минут**                       |
| Успешный вход        | Счётчик попыток сбрасывается                     |

Счётчик попыток хранится в `localStorage` и сохраняется между сессиями браузера.

### Автоблокировка

Приложение автоматически блокируется через **5 минут бездействия** (нет движения мыши, нажатий клавиш или касаний экрана). При блокировке ключ шифрования удаляется из памяти.

## Рекомендации по безопасности

1. **Используйте только на личных устройствах**
   - Не используйте на общедоступных компьютерах
   - Не используйте на рабочих устройствах компании

2. **Защитите устройство**
   - Используйте пароль/PIN/биометрию для разблокировки
   - Включите шифрование диска
   - Регулярно обновляйте ОС и браузер

3. **Безопасность браузера**
   - Используйте актуальную версию браузера
   - Не используйте режим "инкогнито" (данные удалятся)
   - Регулярно делайте резервные копии данных через функцию экспорта

4. **Мастер-пароль**
   - Используйте надёжный пароль (8–128 символов, обязательно минимум одна цифра)
   - Запомните или надёжно сохраните пароль - восстановление невозможно
   - Не используйте один пароль с другими сервисами

5. **При утере устройства**
   - Удаленно очистите данные браузера (если возможно)
   - Смените PIN-коды карт при необходимости

### Очистка данных

Данные можно полностью удалить:

- Кнопкой "Очистить всё" в приложении
- Через DevTools → Application → IndexedDB → card-holder-db
- Очисткой данных сайта в настройках браузера

## Технические меры безопасности

- **Шифрование at-rest** - AES-GCM 256-бит для всех чувствительных полей карт
- **PBKDF2** - 600 000 итераций SHA-256 для защиты от атак на пароль
- **Мастер-пароль в памяти** - ключ шифрования никогда не персистируется
- **Rate limiting** - защита от brute-force атак на мастер-пароль
- **Автоблокировка** - удаление ключа из памяти при бездействии
- **TypeScript в strict mode** - предотвращение ошибок типизации
- **Content Security Policy (CSP)** - защита от XSS (в dev и preview/production сборках)
- **Strict-Transport-Security (HSTS)** - принудительный HTTPS в preview/production сборке (`max-age=31536000; includeSubDomains`)
- **Security HTTP-заголовки** - `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Cross-Origin-Opener-Policy: same-origin`, `Permissions-Policy`
- **HTTP-предупреждение** - баннер и логирование при работе по незащищённому протоколу
- **Схемы [Zod](https://zod.dev/)** - валидация формы карты и паролей (длина, формат, алгоритм Луна для PAN)
- **Валидация вводов** на клиенте до сохранения в IndexedDB
- **98%+ покрытие тестами**
